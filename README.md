# org-code-ai
AI-powered multi-repo intelligence for GitHub organizations.

## Tech Stack
Next.js 15 + GitHub GraphQL + CrewAI + Supabase + OpenAI

## Setup
```bash
pnpm install
cp .env.example .env.local
docker-compose up -d
pnpm turbo dev
```

Dashboard: http://localhost:3000 | API: http://localhost:3001
